# Lara Discord Music Bot

Slash-command Discord music bot for Railway.

## Commands

- `/play query` - plays a YouTube search or URL
- `/pause`
- `/resume`
- `/skip`
- `/stop`
- `/leave`
- `/queue`
- `/nowplaying`
- `/shuffle`
- `/loop`
- `/volume amount`

## Railway variable

Add this in Railway > your service > Variables:

```env
DISCORD_TOKEN=your_real_discord_bot_token
```

## Discord invite scopes

Use these scopes:

- `bot`
- `applications.commands`

Use these bot permissions:

- View Channels
- Send Messages
- Embed Links
- Read Message History
- Connect
- Speak
- Use Voice Activity
